# java-digital-wallet-simulation

### 💳 Digital Wallet & Currency Converter (Java)

This project is an advanced Object-Oriented Programming (OOP) simulation of a digital wallet system. It demonstrates complex object interactions where multiple wallet instances can transfer funds to one another with real-time currency conversion.

**Features:**
* **Object Interaction:** Capability to transfer funds between different `DigitalWallet` objects.
* **Smart Currency Conversion:** Automatically detects the currencies (TL or USD) of the sender and receiver, applying a fixed exchange rate if they differ.
* **Input Validation:** Utilizes `do-while` loops to ensure robust user input for currency selection.
* **Transaction Tracking:** Keeps a running tally of the total number of transactions (deposits and transfers) for each wallet instance.

**Tech Stack:**
* Java
* Advanced OOP (Object Passing, Method Overloading Concepts)
* Control Flow (do-while loops, complex if-else logic)
* `java.util.Scanner` for console inputs
